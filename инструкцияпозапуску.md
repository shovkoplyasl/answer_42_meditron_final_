# SM-Clinic — инструкция по запуску

## 1. Структура проекта

SM-Clinic-FINAL/

- backend/ — FastAPI сервер
- frontend/ — веб-интерфейс
- start.bat — быстрый запуск приложения

---

## 2. Требования

Необходимо установить:

- Python 3.11+
- Node.js 18+
- npm

Проверка:

python --version
node --version
npm --version

---

## 3. Первый запуск Backend

Открыть терминал:

cd backend

Установить зависимости:

pip install -r requirements.txt

Запустить:

python -m uvicorn main:app --host 0.0.0.0 --port 8001

Проверка:

http://localhost:8001/docs

---

## 4. Первый запуск Frontend

Открыть второй терминал:

cd frontend

Установить зависимости:

npm install

Запустить:

npm run dev

Открыть:

http://localhost:5173

---

## 5. Быстрый запуск

Для последующих запусков:

дважды нажать start.bat

Файл автоматически:
- запускает backend;
- запускает frontend;
- открывает сайт.

---

## 6. Демонстрационный сценарий

1. Открыть сайт.
2. Выполнить вход.
3. Выбрать пациента.
4. Загрузить медицинский протокол.
5. Получить анализ и маршрут пациента.
6. Создать запись на консультацию.

---

## 7. API

Backend:
http://localhost:8001

Swagger:
http://localhost:8001/docs

Основные методы:

POST /api/v1/analyze
POST /api/v1/patients
GET /api/v1/patients/{patient_id}
GET /api/v1/patients/{patient_id}/routes

---

Система является демонстрационным прототипом.
Результаты маршрутизации требуют подтверждения медицинским специалистом.
